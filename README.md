# Selk-Companion-Computer

## Install

Run the following commands in the terminal
```bash
cd ~
git clone -b scope-1-opi5+ https://github.com/KelpieRobotics/Selk-Companion-Computer scope-1/
bash ./scope-1/scripts/setup.sh
```

## Running

All required components should be started on boot. If that's not the case, you can launch all modules manually using the following command:

```bash
bash ./scope-1/scripts/start.sh
```
